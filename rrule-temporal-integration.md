# RRule-Temporal Integration for Time Slots

## Summary

We've updated the time slot pattern generation to use the proper `rrule-temporal` library instead of creating custom patterns. This ensures consistency and compatibility with standard RRule specifications.

## Changes Made

### 1. Database Schema
- **Removed** the `pattern_rrule_basic_check` constraint that was enforcing a specific RRULE format
- Generated migration: `drizzle/0016_groovy_stardust.sql`
- Applied migration to drop the constraint

### 2. TimeSlotService (`src/lib/services/timeslot-service.ts`)
- **Updated `generatePattern()`**: Now uses `RRuleTemporal` to generate proper RRule strings
- **Updated `generatePatternFromRecurrence()`**: Uses the existing `toRuleStr()` utility function
- Imports `RRuleTemporal` and `Temporal` for proper pattern generation

### 3. Draw Schedule Page (`src/routes/admin/draw-sessions/[id]/schedule/+page.server.ts`)
- **Synthetic slot generation**: Uses `RRuleTemporal` to create proper RRule patterns
- **Pattern parsing**: When creating slots from synthetic patterns, uses `new RRuleTemporal({ rruleString: pattern })` to parse
- **Deduplication key**: Still uses simple format (`fieldId:WEEKDAY HH:MM-HH:MM`) for efficient merging

## Pattern Format

The patterns now follow the standard RRule format:
```
DTSTART;TZID=UTC:20250901T090000
RRULE:FREQ=WEEKLY;BYDAY=MO
```

This is generated by the `rrule-temporal` library and ensures:
- ✅ Standard compliance with RFC 5545
- ✅ Proper timezone handling
- ✅ Correct date/time formatting
- ✅ Compatible with calendar applications

## How It Works

1. **Synthetic Slot Generation**:
   ```typescript
   const rule = new RRuleTemporal({
     dtstart: dtstart,
     freq: 'WEEKLY',
     byDay: [weekday],
     count: 1
   });
   const pattern = rule.toString();
   ```

2. **Pattern Parsing for Persistence**:
   ```typescript
   const rule = new RRuleTemporal({ rruleString: pattern });
   const occurrences = rule.all((_, i) => i < 1);
   const startUtc = new Date(occurrences[0].toInstant().epochMilliseconds);
   ```

3. **Recurrence Pattern Generation**:
   ```typescript
   // Uses the existing toRuleStr utility
   return toRuleStr(recurrence, timeWindow);
   ```
